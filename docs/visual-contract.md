# Visual contract

Five-scene data-science portfolio for a reader with no prior context: problem, findings, experiment, reliability, action. Each scene leads with one question and a real evidence visual. Main copy is brief; methods, sources, limitations and exact tables use native details disclosures. Native HTML, CSS and JavaScript, light background, dark ink, one teal accent, system sans-serif. Design variance 3, motion 2, density 3. No em dashes, decorative maps, fake charts or employer targeting.

Desktop: sticky chapter links with an active-section indicator; split introduction with a workflow diagram; selectable ranked bars feed the monthly chart; model accuracy bars and chronological timeline; rounded 100-dot reliability breakdown; one-click fixed example predictions. Normal scrolling with reduced-motion support.

Mobile: one column, readable chart labels, minimum 44px controls, visible keyboard focus and horizontal scrolling confined to evidence tables. Charts use the frozen SQL/model values; sample denominators and rounded-dot interpretation remain visible. Missing model preserves findings; missing data offers retry. No arbitrary visitor text or private upload. Raw narratives stay private. The project demonstrates priorities and category prediction, with operational improvement reserved for a proposed pilot.
