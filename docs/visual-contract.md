# Visual contract

Dashboard-first analytical portfolio for a reader with no prior context. A compact purpose statement leads directly to linked findings and monthly evidence, followed by model accuracy and review coverage. Four chapters explain the problem, data and methods, results, and discussion. Default copy is brief; methods, source links, limitations and exact tables use native details disclosures.

Light off-white background, white analytical surfaces, dark ink and one teal accent. System sans-serif, tabular numerals, fine borders, consistent 8px component corners, minimal shadows. Native HTML/CSS/JavaScript. No em dashes, invented maps, fake metrics, decorative badges, employer targeting, profile widgets or permanent sidebar. Design variance 3, motion 2, density 4.

Desktop: compact navigation with visible GitHub link; three-item summary strip; selected finding bars beside their monthly trend; compact accuracy and rounded 100-dot reliability panels. Meaningful chart content must appear within a 1440×1000 first viewport. Selecting a finding updates adjacent evidence in place. Chapters use a narrow editorial label column and a wider reading column.

Mobile: purpose and summary first, then readable findings, trend and model panels. Selection brings the corresponding trend into view. No tiny chart labels or page overflow; tables may scroll inside labelled regions. Minimum 44px controls, keyboard focus, accessible chart descriptions/tables and reduced-motion support.

Charts and numbers derive from the frozen SQL/model exports. Denominators and rounded-dot interpretation remain visible. Missing model preserves analytical results; missing data offers retry. No arbitrary visitor text, private uploads or raw narrative publication. Operational improvements remain proposed pilots.
