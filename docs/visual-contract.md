# Visual contract

Analytical dashboard for customer-insights and service-operations readers. Native semantic HTML and CSS, with a Carbon-inspired density rather than a claimed Carbon implementation. Light theme, dark ink, one teal accent, system sans-serif typography. Design variance 3, motion 2, visual density 5. No decorative images, fake charts, or unsupported evidence badges.

Desktop: navigation, an immediate decision summary, count/quality/model metrics, then detailed evidence. Mobile: one-column stacking, horizontal scrolling only within labelled table regions, minimum 44px controls, visible keyboard focus. Charts use real SQL-derived values with adjacent accessible tables. Never hide denominators or the sample caveat. Empty filters show a clear message. No private uploads or free-text submission in the public service; inference uses fixed synthetic examples only.
