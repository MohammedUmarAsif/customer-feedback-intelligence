# 60-second demo

**0–10 seconds:** “This uses an official historical CFPB narrative sample. Complaints are self-selected, so these are investigation signals, not customer failure rates or TAMM findings.”

**10–25 seconds:** “The shortlist separates volume from change. Debt not owed, account management and purchase disputes recur. Each recommendation includes an alternative explanation and a next check using operational data.” Open one evidence detail.

**25–35 seconds:** Filter to Mortgage and Trouble during payment process. “Every share shows its sample denominator. These six months do not establish seasonality or a cause.” Reset the filters.

**35–50 seconds:** “The chronological June test matches roughly 71 labels per 100, versus 25 for a majority baseline. About half go to review. Accepted cases match about 90 per 100; that quality depends on accepting only half.” Open the class results to show that performance varies.

**50–60 seconds:** Run a fixed synthetic example. “Inference works locally in the browser. The anonymous queue shows cases requiring local human inspection. The repository contains SQL, source hashes, tests and my pending personal review checklist.”
